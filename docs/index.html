      候補は OpenStreetMap の駅データ(東京・千葉周辺)から作ります。

      対象エリアの決め方

      鉄道の路線網(JR・メトロ・都営・私鉄)で A と B を結ぶ経路を調べ、 「A→その駅→B」の所要時間の目安が、最短経路の何倍以内に収まる駅を対象にします。

      遠回りの許容倍率1.6 倍
      職場駅から別の駅へ乗り継げる距離3 km

      例: 3km にすると、職場駅から 3km 以内の別の駅(別の路線の駅を含む)へ、バス等で移動できるとみなします。 0 にすると職場駅に直接乗り入れる路線だけで考えます。

      このアプリについて

      位置情報は使用しません。入力内容や表示状態は保存しません(再読み込みで初期状態に戻ります)。 路線・駅・映画館は OpenStreetMap 由来のデータで、抜けや誤りがある場合があります。
