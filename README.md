# 居住エリア検討マップ

2つの職場の駅から、住む駅の候補を検討するためのモバイル向け地図アプリ(単一HTML)。
初期の基準駅は 東京 と 千葉。画面の設定から任意の駅に変更できる(変更内容は保存されない)。

- `docs/index.html` … アプリ本体(GitHub Pages の公開対象)

## 機能

- 地図: Leaflet + 国土地理院 淡色地図(OSM標準タイルに切替可)
- 路線・駅・大手映画館: OpenStreetMap(Overpass API から実行時に取得)
- 対象エリア: 鉄道の路線網(JR・メトロ・都営・私鉄)で職場A駅とB駅を結べる駅。
  「A→その駅→B」の所要時間の目安が A→B 最短の 1.6 倍以内(設定で 1.1〜2.5 倍)の駅を対象にする。
  職場駅から 3km 以内(設定で 0〜5km)の別の駅へはバス等で乗り継げるとみなす。
- 基準駅(職場A/B)の変更: 設定 → 駅名で検索
- 地点/駅をタップ: 最寄り駅、A・Bまでの通勤時間の目安、合計と差、最寄りの大手映画館
- 初回読み込みの進捗表示(抽出の経過秒、ダウンロード%、各処理の%)
- 位置情報は使わない。状態は保存しない(再読み込みで初期状態)。

通勤時間は直線距離からの概算(徒歩=距離×1.3÷80m/分、電車=駅間直線距離÷35km/h+8分)。
係数は `docs/index.html` の `CONFIG.estimate`、対象エリア判定の係数は `CONFIG.route` にある。いずれも仮の値。

## 公開手順(GitHub Pages)

1. リポジトリを公開(Public)にする。
2. Settings → Pages で、ソースを「Deploy from a branch」、ブランチとフォルダ `/docs` を選ぶ。
3. 表示された URL を共有する。

## 注意

- Overpass API・地図タイルの利用条件は各提供元の規約を確認すること。
- 路線・駅・映画館は OpenStreetMap 由来のデータで、抜けや誤りがある場合がある。
